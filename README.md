# Diamond Enterprise - Salary Slip Portal

Employee salary slip portal for Diamond Enterprise.

## Access
- **Employee Portal:** https://[your-username].github.io/salary-portal
- **Admin Panel:** Contact HR department

## Features
- PAN-based verification
- Monthly salary slips
- Print support
- Mobile responsive

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Supabase
- Hosting: GitHub Pages
